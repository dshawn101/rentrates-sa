# Author tools beta

Available to free beta authors; no new subscription requirement.

- **Templates:** My Books → Start new book → Blank, Fiction, Nonfiction or Memoir. Preview titles before creating. Template metadata supplies suggested genre/word count; after Setup, an empty new Outline loads editable titles and planning descriptions. Saving the outline creates blank chapters. Descriptions remain outline notes, not manuscript text. Existing or archived chapters prevent automatic template seeding. Import mode deliberately ignores a selected template.
- **Writing goals:** My Books resume card and the Write step. Choose a total target of 1,000–200,000 words and optional date, or turn it off. Progress uses saved text and excludes archived chapters. Suggested pace includes today; no daily activity log, streak, reminder or completion guarantee is implied. Editing/removing words can reduce progress. A dedicated invoker-rights RPC updates goal fields while preserving other metadata under the database row lock. RLS restricts it to the book owner. A failed save retains prior cloud settings.
- **Interactive walkthrough:** Author guide on Dashboard, My Books, the book wizard, workspace footer and Help Center. Six independently navigable steps with links to the actual workspace, an optional cover skip and a separate self-reported export-review check. Saved progress indicators use loaded book data. Navigation never writes chapters or marks them complete. Step position and the review check are account/book scoped in local storage; restarting clears the check. These are guidance, not a manuscript readiness assessment.
- **Page help and optional AI:** Author guide → Help with this page. Local answers come from the existing help articles and work without an AI key. Only an explicit Ask request sends the question, page name and help excerpts to the author's saved OpenRouter model through the existing authenticated relay. A separate unchecked-by-default choice includes book title, saved word count, target and stage. The helper never reads chapter content or book notes, and has no tools for editing books, changing settings or approving payments. A request never falls back to a different provider. Closing the dialog, switching account or navigating discards the displayed/in-flight answer; a request already sent may still be charged by the provider.

## Validation

Full suite: 219 tests passed, including goal date/pacing calculations, template draft content, optional prompt context, explicit-only AI calls, guide persistence/focus, template selection versus import, failed goal saves and database metadata/ownership checks. Production build passed. A live SQL check created a synthetic book inside a transaction, verified goal preservation and cross-account denial, then rolled back. No paid AI requests were sent.

Beta author acceptance: use a copy of the author's manuscript to review template creation, real saved word counts and export navigation. This implementation does not claim a test with the author's own manuscript or a paid OpenRouter request.
